# Master School Martial Arts - Landing Page

Esta é a página de "Coming Soon" (Em Breve) para a **Master School Martial Arts LLC**, uma empresa B2B de instrução de artes marciais móveis atuando na Flórida Central (Orlando, Winter Garden e Clermont).

## 🚀 Tecnologias Utilizadas

- **HTML5** (Semântico e acessível)
- **Tailwind CSS** (via CDN para desenvolvimento rápido e sem build step)
- **Google Fonts** (Oswald e Inter)

## 🎨 Design

O design foi concebido com uma paleta de cores premium:
- **Deep Slate Dark Navy:** `#0F172A`
- **Crimson Accent Red:** `#DC2626`
- **Clean White:** `#FFFFFF`
- **Subtle Gold:** `#D4AF37`

Apresenta efeitos modernos de UI/UX, como *Glassmorphism* (cartões translúcidos), gradientes escuros e design totalmente responsivo (Mobile-First).
